# AI 选模助手 · AI Model Picker

**按任务选对模型，用好已付费的 AI 订阅；继续在原客户端工作。**

[English](README.md) · [详细使用教程](docs/USER_GUIDE.zh-CN.md) · [功能清单](docs/FEATURES.md) · [下载](https://github.com/Gavinluo19/ai-model-picker/releases) · [验证与限制](docs/RELEASE_STATUS.md)

你可能已经使用 ChatGPT、Claude，也会通过 TRAE 国内版或 WorkBuddy 使用中国模型。真正的麻烦常发生在开始任务前：选哪个工具、哪个型号、哪个思考档位，是否值得换一个模型？

AI 选模助手是一个轻量原生 Mac 工具：描述本次任务，查看四个规则优先级，选择模型和工作区，再打开或尝试准备到原客户端。**需求由你在原客户端发送，聊天和后续工作也继续留在那里。**

**当前 V0.4 是开源 Alpha。** 离线规则及数据更新协议已有本地检查；真实 JEV 分类和四客户端自动准备仍需账户环境验收。安装包使用临时签名，**尚未 Apple 公证**，部分 Mac 会阻止打开。建议先用“离线推荐 → 仅打开 → 复制需求”的手动交接流程。详细边界见[验证与限制](docs/RELEASE_STATUS.md)。

## 适合谁，能解决什么

- 同时使用多个 AI 服务，频繁犹豫“这次该用哪个”的咨询、研究、写作和开发用户。
- 希望保留原客户端的聊天记录、产品功能和订阅使用方式，不愿再迁移到一个新聊天平台的用户。
- 希望把团队经验整理成可查看、可修改、可分享的任务规则的培训者与团队。

它的预期帮助是减少选型犹豫、重复查看型号与档位，以及不必要的高档位使用。**目前没有用户实验能证明节省比例、结果质量提升或真实订阅节省金额。** 如果你只用一个助手且选择已经很顺手，增加选模步骤未必有价值；面向大规模 API 执行或无人值守编码的需求，也有更合适的[相近项目](docs/RELATED_PROJECTS.md)。

## 产品特点与详细功能

| 功能 | 使用者得到的帮助 |
|---|---|
| 保留原客户端 | ChatGPT、Claude、TRAE 国内版、WorkBuddy 适配器已实现；执行任务不改用模型 API，不托管你的聊天历史。自动交接仍是实验能力。 |
| 可审阅的 Markdown 规则 | 13 类常见任务，包含适用/排除、优先与备用、复杂度/档位分支；排名是试行政策，不是已实测能力榜。 |
| 无 Key 可离线使用 | 本机匹配中英文关键词、词组和排除条件；不确定时只问主要任务类别，不冒充完整语义理解。 |
| 可选 JEV 智能分类 | 由 JEV 分类、本机规则推荐；服务失败明确回退离线。需要个人 Key，真实准确率仍待验证。 |
| 四个优先级同页展示 | 内置政策提供两个国际和两个中国模型候选；可直接点选，不用模型下拉菜单。不可用候选只能作参考。 |
| 直观调整工作区与档位 | 横向选择对话、工作、协作或编程，以及型号支持的思考强度；保留原客户端真实菜单核验。 |
| API 参考价格表 | 每百万 Token 输入/输出、人民币/美元对照、来源和日期；默认输出价降序，同价再比输入。不是订阅扣费。 |
| 模型、价格与汇率更新 | 公共目录与日参考汇率同步、本地缓存、部分失败提示及撤销；新发现型号不直接进入业务路由。 |
| 原生 Mac 使用体验 | Dock、菜单栏分叉图标、可最小化窗口、两键/三键自定义快捷键、富文本粘贴、换行、中英文与深浅主题。V0.4 窗口行为仍待实机验收。 |
| 有边界的准备操作 | 设计为核验模式、型号、档位和空输入区后填写；不会自动发送，发现已有草稿或焦点改变就停止。 |

## 五分钟开始

1. 在[Releases](https://github.com/Gavinluo19/ai-model-picker/releases)查看 Alpha 安装包，或从源码构建。未公证的二进制可能被 macOS 阻止；不要关闭安全保护，开发者与测试者优先采用本地构建。
2. 保持要使用的原客户端已安装、已登录。本产品不登录账户、不扩大额度、不授予模型权限。
3. 退出旧版后打开 `AI选模助手.app`。默认快捷键是 **Control + Option + 空格**；也可使用 Dock 或菜单栏入口。
4. 选择“离线推荐”，输入：`梳理一个小型库存应用的软件架构和模块边界。`，点“推荐模型”。
5. 查看结果、选择一张卡，点击“仅打开”和“复制需求”。在原客户端手动设置建议型号/档位、粘贴，再由你发送。这个流程不需要辅助功能权限。

可选：“设置 → JEV 连接”保存个人 API Key，测试认证后再尝试智能推荐。Key 保存在本机钥匙串；智能模式会将本次任务文字与分类条件发给 JEV，并产生你的 API 用量。自动“准备到…”为实验功能，需要辅助功能授权，无法完整核验就停下，不能据按钮出现判断交接已成功。

[详细教程](docs/USER_GUIDE.zh-CN.md)包含真实使用步骤、任务示例、设置、规则/价格更新、权限、常见问题与恢复方法。

## 客户端与账户可用性

| 客户端 | 目标工作方式 | 当前状态 |
|---|---|---|
| ChatGPT | Work / Codex | 适配器已实现；最新客户端及实际账户需要单独验证。 |
| Claude | 对话 / Cowork / Code | 自动准备尚待端到端验收；有橙色访问与账号提醒，不自动启用额外积分型号。 |
| TRAE 国内版 | Work / Code | 菜单与模型可能因版本、地区和账户不同。 |
| WorkBuddy | 日常办公 / Code | 保留客户端档位设置，不自动打开产品 Max。 |

规则与目录里的型号是有日期的候选参考，不保证你的账户存在这些选项。请先看原客户端菜单，再到设置取消不可用型号。公开目录刷新不等于业务路由更新，也不证明账户权限。

## 费用与隐私

软件本身按 MIT 免费开源；原服务订阅、可选 JEV API 与客户端额外用量由使用者承担。离线推荐在本机完成；主动更新目录/价格时会联网到 Models.dev 和 Frankfurter，不发送任务或 Key。分类与交接使用文字，富文本样式留在助手里，不上传粘贴图片。

API 价格只作大概比较，不能换算成你的订阅扣费、剩余次数或一次成功任务的真实成本；人民币/美元是换算对照，不代表两地区实际报价。细节见[隐私说明](PRIVACY.md)与[安全说明](SECURITY.md)。

## 从源码构建

需要 **macOS 14+**、Apple 命令行开发工具；打包还需要系统 Python 3。应用运行本身不依赖 Node、Python 或后台服务器。各原客户端有自己的系统要求。

```sh
git clone https://github.com/Gavinluo19/ai-model-picker.git
cd ai-model-picker
bash scripts/test.sh
bash scripts/build.sh
bash scripts/package.sh
```

输出为 `dist/AI选模助手.app`，安装包包含 Apple Silicon / Intel 双架构。Intel 与最低支持系统的运行尚未验收。产品标记 V0.4，内部版本 1.3.0 build 4；保留原应用身份、Keychain 与自定义规则。

正式二进制发行需要 Developer ID 签名、公证及另一台 Mac 验收，本 Alpha 尚未完成。可选签名方法见[开发说明](docs/DEVELOPING.md)。提供[可自行启用的 macOS CI 模板](examples/github-actions/macos.yml)，不宣传尚未运行的 CI 状态。
