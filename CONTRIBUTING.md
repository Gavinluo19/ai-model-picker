# Contributing / 贡献说明

Welcome: anonymized task examples, clearer Markdown policies, localization, verified client adapters and another-Mac results.

Before a change, open an issue explaining the user problem, expected behavior and scope. Keep patches focused; preserve keys/settings, editable drafts, exact model checks and user-controlled sending. Run `bash scripts/test.sh` and `bash scripts/build.sh`. Report OS/chip and what was actually verified. Do not claim live-service or adapter acceptance from mock tests.

For model updates, include the source/date, exact client menu name, subscription availability observations, supported workspace/effort and an anonymized task result. API discovery alone is insufficient to enable a new desktop route. Rank rules are hypotheses until validated.

Never contribute API keys, login credentials, real conversations, customer files, personal settings or account screenshots. Redact or reproduce bugs with synthetic examples. Do not copy another project's code without tracking its license.

中文：欢迎匿名样例、规则、翻译、适配器与跨机器验证。先说明使用者问题和改动范围；运行测试与构建；明确哪些步骤实测、哪些仍待验证。新型号要提供准确菜单、来源/日期及工作区/档位证据。不上传 Key、凭证、聊天、客户资料或账户截图。

MIT applies to accepted project contributions; third-party data retains its own notices. Follow SECURITY.md for sensitive reports.
