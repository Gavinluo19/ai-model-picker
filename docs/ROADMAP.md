# Roadmap / 路线图

These are proposals, not shipped claims. / 以下是计划，不是已交付能力。

1. **Validate the alpha / 先验证 Alpha** — test V0.4 windows on an unlocked Mac, one real JEV task, all four adapters on declared app versions, and another Mac. Keep manual Open + Copy as fallback.
2. **Measure task value / 测任务价值** — a small cohort with repeated anonymized tasks; compare selection-to-start time, manual overrides, rework and repeat use. No cost-savings claims before evidence.
3. **Improve policies / 改进规则** — maintain bilingual task templates and versioned rule examples; accept current-model contributions only with menu/access verification and realistic task evidence.
4. **Prepare signed distribution / 正式分发** — Developer ID signing, notarization, minimum-OS/Intel tests and a stable build/release pipeline.
5. **Consider feedback-driven routing / 再考虑反馈路由** — local feedback and policy adjustment only after repeat use; any uploaded analytics require an explicit design and user consent.

Not planned for the initial release: credential proxies, quota farming, automatic purchases, guaranteed ranking, broad account scraping, or an unattended multi-agent platform. / 首版不做凭证代理、额度套利、自动购买、保证排名、账户爬取或大型无人值守平台。
